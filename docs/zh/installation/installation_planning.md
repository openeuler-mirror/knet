# 组网规划

介绍K-NET网络加速套件部署前的组网规划，包括服务端与客户端的角色划分、物理机与虚拟机两类组网模型及Bond场景组网。阅读本指南后，您将能确定适用于自身环境的测试组网方式。

测试组网模型如下：

- 服务端：在物理机或者虚机安装业务服务端（Server）和<term>K-NET</term>网络加速套件。
- 客户端：运行业务客户端（Client），向服务端发起请求以及性能测试。
