# fork

介绍K-NET的fork接口，面向应用开发工程师。涵盖接口功能、参数说明、返回值及错误码，并说明子进程不支持TCP/UDP/IP协议通信的限制，适用于创建子进程的开发场景。

## 接口名称

**fork(void)**

## 接口描述

创建子进程。

> [!NOTE]说明
>不支持fork的子进程使用TCP/UDP/IP协议通信。

## 参数说明

无

## 返回值

类型：pid_t

- 正数：表示在父进程中，fork创建的子进程的进程ID。
- 0：表示在子进程中，返回值为0。
- 负数：表示失败，并设置errno以指示错误类型。

## 错误码

|错误码|描述|
|--|--|
|ENOMEM|系统内存申请失败。|
|ELIBBAD|系统符号加载失败。|
